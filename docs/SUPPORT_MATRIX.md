## Status terms

- **Verified** — observed on the stated physical build.
- **Partial** — only part of the diagnostic or repair path was verified.
- **Experimental** — implementation exists but physical behavior is not yet established.
- **Unknown** — the platform did not expose enough evidence to classify the state.
- **Unsupported** — the required mechanism is absent or intentionally not supported.
